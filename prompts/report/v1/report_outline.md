# Required report outline

1. `R01_EXECUTIVE_FINDINGS`: principal supported results, material exceptions, and review status.
2. `R02_DATA_VALIDATION`: sources, observation period, schema checks, exclusions, data-quality findings, and reconciliation status.
3. `R03_POPULATIONS_EXPECTED_BASIS`: Total/Core/Modern definitions, nesting, expected-death fields, VBT basis, mortality improvement, and independent XML validation.
4. `R04_EXPOSURE_AND_TRENDS`: exposure composition, actual and expected mortality, count and amount A/E, uncertainty, and observation-year/duration trends.
5. `R05_PRODUCT_RESULTS`: product, plan, face amount, and cross-segment results.
6. `R06_SEX_SMOKER_RISK_CLASS`: sex, smoker, preferred indicator, number of classes, class rank, and Select/Ultimate results.
7. `R07_AGE_AND_DURATION`: issue age, attained age, duration, juvenile, and older-age results.
8. `R08_MODEL_DIAGNOSTICS`: approved model specifications, time split, calibration, diagnostics, sensitivities, and deterministic follow-up evidence.
9. `R09_PRACTICAL_IMPLICATIONS`: supported actuarial or operational implications without prescriptive overreach.
10. `R10_LIMITATIONS_GOVERNANCE`: limitations, reliance, appropriate use, methodology changes, sparse cells, governance, and independent review requirements.
11. `R11_REPRODUCIBILITY_REFERENCES`: reproducibility, provenance, exhibit index, definitions, and references.

The title, practitioner summary, unresolved-issue register, exhibit index, and reference list are required top-level report elements in addition to these sections.
